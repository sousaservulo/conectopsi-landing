# ConectoPsi — Landing de homologação

Landing page estática e independente criada para ser publicada futuramente no GitHub Pages enquanto a aplicação principal do ConectoPsi permanece em homologação.

## Estrutura

- `index.html` — página principal
- `styles.css` — estilos responsivos, sem framework
- `assets/logo.jpeg` — logo reaproveitada do projeto atual
- `assets/favicon-*.png` e `assets/apple-touch-icon.png` — ícones derivados da logo
- `robots.txt` e `sitemap.xml` — SEO básico

## Teste local

Você pode abrir `index.html` diretamente no navegador ou, na pasta do projeto, executar:

```bash
python -m http.server 8080
```

Depois acesse `http://localhost:8080`.
